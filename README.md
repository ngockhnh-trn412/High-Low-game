Welcome to my first project on Github! This is a number guessing game.
About this game:
-The computer will choose a number from 1 to 100
-You need to guess the secret number based on the computer's hints
-After each guess, the computer will tell you whether your guess is smaller or bigger compared to the secret number
To play this game:
-Click the CODE then click the Download ZIP and extract it
-Open 'numberguessing.cbp' with Code Blocks(or just open 'main.cpp' in your IDE)
-Press 'Build and Run' to play!
